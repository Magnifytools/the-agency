# P73 — Timer y tarea directa de Captura

1. Trazar el contrato de creación/inicio desde la extensión hasta el selector global del Timer.
2. Reproducir mediante una prueba focal el caso: crear/iniciar, parar y volver a seleccionar la tarea.
3. Corregir la causa raíz manteniendo permisos, elegibilidad y paginación.
4. Añadir al selector de Timer las capturas directas históricas, sin incluir trabajo de otras personas.
5. Ejecutar las pruebas focales y la comprobación de compilación pertinente.
